# Contributing

1. Fork the repo and create a branch.
2. Add or fix a resource in the right file (`foundations/`, `embedded/`, or `vlsi/`).
3. Each resource line should follow this format:
   `- [Title](link) — author/channel, type (book/video/course/tool), level (L0-L3), free/paid`
4. Open a pull request with a short description of what you changed.
